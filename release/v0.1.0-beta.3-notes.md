# Voxelle 0.1.0 beta 3

This release adds the first Windows x86-64 NSIS installer to the signed beta
artifact set. The same independently authenticated manifest covers the
universal macOS DMG, Windows installer, and live product-generation package.

The Windows application is cross-compiled with the Microsoft ABI, carries the
Windows GUI subsystem, and now embeds SQLite consistently across supported
platforms. Release assembly refuses to sign a beta artifact set unless both
native installers are present.

The Windows installer has received structural cross-build verification, but
has not yet been installed and launched on native Windows hardware. It is
unsigned by a Microsoft-recognized publisher, so SmartScreen may warn. Package
authenticity is instead established by `VOXELLE-RELEASE.json` and the release
root embedded in Voxelle; `SHA256SUMS.txt` remains an adjacent convenience.

See
[`docs/INSTALL_UNSIGNED.md`](https://github.com/x3haloed/voxelle/blob/v0.1.0-beta.3/docs/INSTALL_UNSIGNED.md)
for the narrow platform-specific installation guidance.
