First signed live-product-generation beta preview.

Included:

- Universal macOS DMG for Apple Silicon and Intel
- Signed in-process product generation package
- Ed25519-signed `VOXELLE-RELEASE.json` covering the exact shipped bytes

Verify the manifest before installation or activation using
[`docs/INSTALL_UNSIGNED.md`](https://github.com/x3haloed/voxelle/blob/v0.1.0-beta.1/docs/INSTALL_UNSIGNED.md).
The macOS app uses an ad-hoc hardened-runtime signature and therefore has no
Apple publisher identity; narrow first-launch instructions are documented.

Windows packaging and native Windows execution remain a beta gate and are not
claimed by this preview.

Although the signed channel is `beta`, this GitHub release is intentionally not
marked pre-release: installed kernels use GitHub's fixed
`/releases/latest/download` transport path, while cryptographic policy comes
from the signed manifest.
