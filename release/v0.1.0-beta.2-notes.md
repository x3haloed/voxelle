Signed live-product-generation beta preview for macOS.

This sequence closes the native offline-inviter onboarding path: `Create Space
Invite` now includes eligible known members as bounded, signed bootstrap hints.
A fresh installation can therefore use the inviter's membership authority while
synchronizing through an ordinary retaining peer after that inviter goes
offline. Endpoint hints still grant no membership or protocol authority.

Included:

- Universal macOS DMG for Apple Silicon and Intel
- Signed in-process product generation package, sequence 2
- Ed25519-signed `VOXELLE-RELEASE.json` covering the exact shipped bytes
- Explicit GitHub discovery, staging, activation, rollback, and release-root
  transition surfaces

Verify the manifest before installation or activation using
[`docs/INSTALL_UNSIGNED.md`](https://github.com/x3haloed/voxelle/blob/v0.1.0-beta.2/docs/INSTALL_UNSIGNED.md).
The macOS app uses an ad-hoc hardened-runtime signature and therefore has no
Apple publisher identity; narrow first-launch instructions are documented.

Windows packaging and native Windows execution remain a beta gate and are not
claimed by this macOS preview. The signed manifest declares the `beta` channel;
the GitHub entry is intentionally an ordinary latest release so installed
kernels can use the fixed `/releases/latest/download` transport path.
