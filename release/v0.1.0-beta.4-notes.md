# Voxelle 0.1.0 beta 4

This release candidate brings the current human and agent experience onto one
reviewed source generation. It keeps identity, governance, synchronization,
private-room, and release authority in the Rust command host while making their
states and recovery paths more legible.

Human-facing changes include goal-first onboarding, explicit damaged-home and
startup recovery, draft-safe customization, focused review for consequential
actions, peer-specific connection recovery, and clearer direct-media degraded
states. Buttons, keyboard shortcuts, the command palette, and native automation
continue to use the same stable semantic command vocabulary.

The authenticated loopback inhabitant surface now exposes the generated Rust
request contract, identifies each shell command's payload type, emits monotonic
snapshot-change wakeups, and attributes only the Rust-owned service activity
observed during each serialized action. It does not grant agents separate
protocol authority.

The universal macOS DMG and Windows x86-64 NSIS installer remain unsigned by
Apple- or Microsoft-recognized publishers. Authenticate their exact bytes with
`VOXELLE-RELEASE.json` and follow the narrow instructions in
[`docs/INSTALL_UNSIGNED.md`](https://github.com/x3haloed/voxelle/blob/v0.1.0-beta.4/docs/INSTALL_UNSIGNED.md).

Native Windows launch, physical multi-peer networking, assistive-technology,
physical media, public readback, and offline signing-custody observations remain
release-receipt gates. Artifact availability alone does not satisfy them.
